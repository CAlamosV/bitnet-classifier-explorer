We assign institutions at the paper-author level: for a given paper, author A can be attached to Berkeley while author B is attached to Stanford if the underlying authorship data records those affiliations separately. The file is not an all-paper-institutions-to-all-authors expansion.

How well does it work?

We validate the author-institution file against faculty rosters for Stanford, UC Berkeley, UC Davis, and UCLA. The main check asks: when the roster data say a matched person is at one of these schools in a stable year, does the paper-author affiliation include that school?

How the institution file is built

We start from SciSciNet/OpenAlex paper-author-institution rows and keep only institutions whose OpenAlex type is education. The goal is a university/college affiliation file for publication analysis, not a complete employer-history file.

For each PaperID, AuthorID slot we collect the author's education-affiliation observations in a ±3-year window around the publication year. The most-common institution in that window (the “modal” institution) is the candidate. If it accounts for at least 75% of the window observations and shows up on at least 4 papers, we assign it — even if a single raw row on the paper says something different. This is what catches obvious coauthor-leak rows where a visiting Stanford coauthor's affiliation gets propagated to every author on the paper.

If the strong-window rule does not fire, we fall back to the raw paper-author-institution row. Slots that have no raw row at all get filled by the same window vote at a more permissive threshold (50% of observations, at least 2 papers). Slots with neither raw nor window evidence get filled only when the author's nearest pre- and post-gap years agree on a single institution. Roughly a third of the file is from raw rows, a third is window-filled, and a small share is long-distance-interpolated; less than 1% is window-strong override.

How to read it

The file is useful for asking where authors appear to be publishing from in a given paper-year. It is not a personnel roster. It can miss campus labels when OpenAlex records a parent system, medical campus, or older institution name, and it can be noisy for authors with common names or genuine multi-institution careers.

The institution candidate browser shows the OpenAlex authors attached to a chosen university, year, and field without using faculty roster data.
